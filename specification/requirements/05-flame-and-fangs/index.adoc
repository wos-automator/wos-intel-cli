== Flame and Fangs Event

Once every four weeks the Flame and Fangs event pays Crystallite Cores for every claimed hunt
reward (SPEC.md §3.7). The day before the event, the run moves as many mission rewards as
possible into the event. During the event, the firebeast pin is worked on as a hunt.
