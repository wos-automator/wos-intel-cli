[[FR-5.2]]
=== FR-5.2 Mission expiry

Every mission dialog except the boss shows "Intel Expires In HH:MM:SS" in dark text above the
"View" button.

.Acceptance criteria
. The expiry is read from every mission dialog that shows it; on the reference dialogs it reads
  the time the dialog shows.
. The boss dialog has no expiry; the result is "none", never a guessed time.
. A digit that cannot be recognised makes the whole expiry "unreadable".
. The expiry is only read while the event icon is shown (<<FR-5.1>>).
