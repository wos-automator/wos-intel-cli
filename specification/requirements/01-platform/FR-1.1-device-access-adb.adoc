=== FR-1.1 Device access via ADB only

The program reads the screen and sends taps and BACK exclusively through ADB, to one selected
device.

.Acceptance criteria
. A second attached device never causes "more than one device": every call addresses the
  selected one.
. `ANDROID_SERIAL` overrides the configured serial; without it `127.0.0.1:5555` is used.
. A screenshot that cannot be decoded or is not 720x1280 is an error.
. A failing, missing or hanging `adb` ends the program with a message and exit code 1.
