=== FR-1.2 Device check at start

Before the first input the program verifies that the device is usable.

.Acceptance criteria
. `adb get-state` must report `device`.
. `adb shell wm size` must report `Physical size: 720x1280`; anything else aborts the run.
. The package `com.gof.global` must own the focused window; otherwise the run aborts.
. In all three cases no tap and no BACK is sent.
