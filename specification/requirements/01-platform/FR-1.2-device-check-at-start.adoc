=== FR-1.2 Device check at start

Before the first input the program verifies that the device is usable.

.Acceptance criteria
. The device must be connected and ready; otherwise the run aborts.
. The screen must be 720x1280; anything else aborts the run.
. The game (package `com.gof.global`) must be in the foreground; otherwise the run aborts.
. In all three cases no tap and no BACK is sent.
