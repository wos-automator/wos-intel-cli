=== US-2.3 Stamina and refresh timer

Status:: Done (0.1.0) +
Effort:: 6 h +
Traces to:: <<TS-2.3>>, <<FR-2.5>>

As the run loop, I want the stamina and the remaining refresh time as numbers, so that I can
skip unaffordable missions and lock the boss for the right time.

.Acceptance criteria
. Stamina: 2047 (`intel-x.png`), 2035 (`intel-xx.png`, `intel-xxx.png`).
. Refresh timer: 25167 s, 25150 s, 25145 s.
. `intel-boss-running.png`: stamina 1975, refresh timer 9963 s (02:46:03, touching "46").
. Screens without these texts read as `None`.
. The digits 1, 6, 8 and 9, which never occur in the stamina of the references, are read from
  the troop number 169,830 of the Deploy screen.
. `tools/cut_templates.py` regenerates all digit templates from `ref/`.

.Test criteria
* Unit test (pytest, `tests/test_detect.py`): values per screenshot, `None` cases, glyph
  normalisation, hue distance.
