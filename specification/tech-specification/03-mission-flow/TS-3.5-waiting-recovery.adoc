[[TS-3.5]]
=== TS-3.5 Waiting and recovery

Implements <<FR-3.6>>.

* `_tap` / `_back`: log, send, `sleep(timing.tap_delay)`.
* `_observe`: `_look` (fresh screenshot → `detect_state`; logs the state; writes
  `debug/<step>-<STATE>.png` when debugging). While the state is `HINT` – at most `limits.max_back`
  times, never in a dry run – the `hint` match is tapped and `_look` repeated, so every caller
  sees the screen below the hint (<<US-5.1>>). On `SESSION_LOST` it calls `_reconnect`.
* `_reconnect`: `sleep(timing.reconnect_delay)`; a fresh screenshot that still shows
  `SESSION_LOST` gets a tap on `btn_reconnect`; then `_expect(INTEL* | WORLD,
  timing.reconnect_timeout)` – meanwhile `_reconnecting` keeps `_observe` from reconnecting
  again – and `raise Reconnected` (<<US-5.4>>).
* `_expect(states, timeout=timing.expect_timeout)`: observe; return on a wanted state; raise
  `StepFailed` once the deadline has passed; otherwise `sleep(timing.poll_interval)` and
  repeat.
* `_recover`: `Reconnected` and `StepFailed` end the recovery (the reconnect has already led
  back to `INTEL*` or `WORLD`). Up to `limits.max_back` times: observe; stop on `INTEL*` or `WORLD`; `REWARDS` → tap the
  rewards exit; `VICTORY`/`DEFEAT` → tap the exit text; `QUIT_CONFIRMATION` → tap `btn_cancel` and stop
  (<<US-5.2>>); anything else → BACK.

* `_save_failure`: on `MissionRejected` and `StepFailed` the last observed screenshot is written
  unannotated to `debug/failure-<step>-<STATE>.png` (`failure_dir`, always set by the CLI), so
  that an unknown dialog can be turned into a reference.

Failed steps in a row are counted in `Runner.run`; `limits.max_failures` of them end the run
with `TOO_MANY_FAILURES` (<<TS-3.2>>).

`sleep`, `clock` and `now` are injected, so the tests run without real waiting. Checked by
`tests/test_flow.py` against the fake game (<<ADR-3>>): `test_expect_polls_until_the_timeout`,
`test_simple_battle_mode_hint_*`, `test_unknown_screen_is_left_with_back`,
`test_quit_confirmation_after_back_is_cancelled`, `test_session_is_reclaimed_*`,
`test_login_elsewhere_during_a_mission_costs_no_failure`,
`test_run_ends_after_three_consecutive_failures`, `test_screenshot_of_a_skipped_mission_is_kept`.
