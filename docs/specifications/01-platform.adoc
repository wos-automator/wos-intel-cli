== Platform: Device Access, Command Line, Configuration

[#FR-1.1]
=== FR-1.1 Device access via ADB only

The program reads the screen and sends input exclusively through ADB: `adb exec-out screencap -p`,
`adb shell input tap` and `adb shell input keyevent KEYCODE_BACK`. The device is selected by
`ANDROID_SERIAL` (default `127.0.0.1:5555`).

.Acceptance criteria
. Every ADB call carries `-s <serial>`, so a second attached device never causes
  "more than one device".
. `ANDROID_SERIAL` overrides the configured serial; without it `127.0.0.1:5555` is used.
. A screenshot is returned as a 720x1280 BGR image; an undecodable or differently sized image
  is an error.
. A failing, missing or hanging `adb` ends the program with a message and exit code 1.

Stakeholder need:: SPEC.md §1 (Device access, Device) +
Effort:: 3 h

[#FR-1.2]
=== FR-1.2 Device check at start

Before the first input the program verifies that the device is usable.

.Acceptance criteria
. `adb get-state` must report `device`.
. `adb shell wm size` must report `Physical size: 720x1280`; anything else aborts the run.
. The package `com.gof.global` must own the focused window; otherwise the run aborts.
. In all three cases no tap and no BACK is sent.

Stakeholder need:: SPEC.md §1 (Resolution, Package), §5 (start) +
Effort:: 2 h

[#FR-1.3]
=== FR-1.3 Command line interface

The program is started as `python -m wos_intel <command>`.

.Acceptance criteria
. `run` performs a normal run; `run --dry-run` detects and logs but never taps or presses BACK.
. `detect <image>` runs the detection on a 720x1280 image file, logs state, stamina and symbols
  and writes `<image>.debug.png` next to it.
. `snap <name>` stores an ADB screenshot as `ref/<name>.png` and refuses to overwrite an
  existing file unless `--force` is given.
. Exit code 0 for a regular end, 1 for an aborted run or a device/configuration error,
  2 for a usage error.

Stakeholder need:: SPEC.md §7 +
Effort:: 3 h

[#FR-1.4]
=== FR-1.4 Logging and debug images

.Acceptance criteria
. Every log line goes to stdout and starts with a timestamp.
. Logged are: each detected state, each symbol (type, tier, status, position), the stamina and
  each tap or BACK with its reason.
. With `run --debug` every analysed screenshot is saved under `debug/` with the detected
  matches and symbols drawn in.

Stakeholder need:: SPEC.md §7 +
Effort:: 2 h

[#FR-1.5]
=== FR-1.5 Configuration file

Thresholds, wait times and coordinates are configurable in `config.toml`.

.Acceptance criteria
. Without a file the built-in defaults apply; they equal the values of SPEC.md.
. The shipped `config.toml` lists every setting with its default value.
. An unknown section or key, or a value of the wrong type, aborts with a message naming it.
. Relative paths (templates, ref, debug, state file) resolve against the directory of the
  configuration file.

Stakeholder need:: SPEC.md §7 (configuration) +
Effort:: 3 h
