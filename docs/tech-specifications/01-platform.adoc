== Platform: Device Access, Command Line, Configuration

.Module overview
[source]
----
wos_intel/
  __main__.py   CLI: run | detect | snap                      (TS-1.2)
  config.py     defaults + config.toml                        (TS-1.3)
  adb.py        screenshot, tap, back, device check           (TS-1.1)
  detect.py     states, symbols, status, tier, digit OCR      (TS-2.x)
  flow.py       run loop / state machine                      (TS-3.x)
  state.py      state.json, boss lock                         (TS-3.4)
----

`flow.py` depends on `detect.py`, `state.py` and the `Device` protocol; `adb.py` is the only
module that starts a process. `detect.py` is a pure function of screenshot and templates.

[#TS-1.1]
=== TS-1.1 ADB wrapper (`wos_intel/adb.py`)

Implements <<FR-1.1>>, <<FR-1.2>> and <<FR-4.2>>.

[cols="1,3"]
|===
|Member |Contract

|`Adb(config: DeviceConfig)` |Bound to one serial; every call runs `adb -s <serial> ...` with a timeout (`command_timeout`, default 15 s).
|`check() -> None` |`get-state` = `device`; `shell wm size` = `Physical size: 720x1280`; a line with `mCurrentFocus` or `mFocusedApp` of `shell dumpsys window` contains the package. Raises `AdbError` otherwise.
|`screenshot() -> Image` |`exec-out screencap -p`, decoded with `cv2.imdecode` to BGR `uint8`; `AdbError` if undecodable or not 720x1280.
|`tap(x, y) -> None` |`shell input tap`; refuses coordinates outside the screen.
|`back() -> None` |`shell input keyevent KEYCODE_BACK`.
|===

`AdbError` also covers a missing binary, a timeout and a non-zero exit code (stderr in the
message). The class has no swipe, drag, zoom or text method, and nothing in the project talks
to macOS input APIs.

[#TS-1.2]
=== TS-1.2 Command line (`wos_intel/__main__.py`)

Implements <<FR-1.3>> and <<FR-1.4>>.

* `argparse` with the global option `--config <file>` and the sub-commands `run [--dry-run]
  [--debug]`, `detect <image>`, `snap <name> [--force]`.
* `logging.basicConfig` on stdout, format `%(asctime)s %(levelname)-7s %(message)s`.
* `run` wires `Adb`, `Detector`, `StateStore` and `Runner`; exit code 0 if `Outcome.ok`, else 1.
* `detect` logs state, matches, stamina, refresh timer and symbols and writes
  `<image stem>.debug.png` using `Detector.annotate`. Unreadable or wrongly sized image: exit 2.
* `snap` accepts a plain file name only (no directories) and writes `ref/<name>.png`.
* `AdbError`, `ConfigError` and `DetectError` are logged and mapped to exit code 1.

[#TS-1.3]
=== TS-1.3 Configuration (`wos_intel/config.py`, `config.toml`)

Implements <<FR-1.5>>.

`Config` is a frozen dataclass of frozen section dataclasses; the defaults in code are the
values of SPEC.md.

[cols="1,3"]
|===
|Section |Content

|`device` |serial, adb path, package, resolution, command timeout
|`timing` |tap delay 1.0 s, poll interval 0.7 s, expect timeout 8 s, fight timeout 60 s, completion timeout 900 s, completion poll 10 s
|`limits` |max missions 30, max BACK 3, max failures 3, minimum stamina 10
|`costs` |stamina cost per mission type
|`symbols` |search band, white mask, thresholds, disc radius, check mark, tier hues, overlap, dialog pin
|`buttons` |template thresholds, popup band, colour classification, rewards exit point
|`ocr` |white mask for text, stamina and timer region, glyph thresholds
|`boss` |fallback cycle length
|`paths` |templates, ref, debug, state file
|`regions` |search region per template
|===

`load_config(path, env)` reads the file with `tomllib`, replaces only the given keys, converts
lists to tuples and rejects unknown sections/keys and wrong types with `ConfigError`. Without
`path` it uses `config.toml` from the working directory, then from the project root. `base_dir`
is the directory of the file; `Config.path()` resolves relative paths against it.
`ANDROID_SERIAL` overrides `device.serial`.
